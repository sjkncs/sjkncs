# Profile repository

This repository controls the GitHub Overview for `sjkncs`.

- Keep the introduction and selected projects bilingual. Do not invent personal milestones, performance metrics, credentials or deployments.
- Prefer self-contained repository SVGs over externally rendered badges. No emoji in the profile or its SVG assets.
- Keep project descriptions manually curated from public sources. The automatic section describes public repository metadata, not code quality, authorship, completed projects or coding hours.
- `data/profile.json`, `assets/activity.svg`, `assets/projects/*.svg` and the README `activity` block are generated by `scripts/update_profile.py`. Do not edit them by hand. `data/featured.json` contains manually curated project captions.
- Run `python -m unittest discover -s tests -v` and `python scripts/update_profile.py --check` before publishing.
- Refresh with `python scripts/update_profile.py`. GitHub CLI authentication is used locally; CI uses `GH_TOKEN`. Never print credentials.
- Failed or incomplete API collection must leave the previous snapshot in place. The workflow commits only the generated paths and must not publish on pull requests.
- The optional contribution snake is managed separately by `snake.yml`; preserve its output branch.
