# SJKNCS — AI 编程七维治理体系

> **S**ystematic **J**udicious **K**nowledge-based **N**avigation for **C**ode **S**tandards

你正在使用的是一套为 AI 编程助手（Claude Code / CodeBuddy / Cursor）设计的七维治理规则体系。每一维解决 AI 辅助编程中的一个核心痛点。

## 核心原则

1. **谋定而后动** — 任何编码任务前，先建计划、再执行
2. **最小化修改** — 只改动必要部分，不碰无关代码
3. **可回退设计** — 每次重要修改前创建检查点
4. **上下文预算意识** — 时刻关注 token 消耗，懒加载信息
5. **规则驱动** — 用显式规则替代隐式约定

## 七维技能

| 维度 | 技能 |
|------|------|
| 代码优化 | `01-code-optimization` — 重构、性能、代码审查 |
| 规则管理 | `02-rule-management` — 规则创建、版本、冲突处理 |
| 记忆上下文 | `03-memory-context` — 跨会话记忆、上下文持久化 |
| 回退备份 | `04-rollback-backup` — 快照、检查点、安全回滚 |
| 文件分类 | `05-file-classification` — 自动分类、目录规范 |
| Token 节约 | `06-token-saving` — 上下文预算、懒加载、缓存 |
| 同步管理 | `07-sync-management` — 版本追踪、更新同步 |
